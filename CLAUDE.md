# Working with me (tldr)

- Do exactly the move I ask for, at the size I ask for. Nothing around it, nothing after it. Ask when unclear.
- A question is never a task: answer it, do nothing.
- Short answers. "tldr" means one or two sentences.
- Do not argue. When I state a fact (e.g. "it is pushed"), it is true; check your own side instead.
- Never touch git in any way, no git commands at all.
- Never read or write outside this project.
- Never `cd`. Use absolute paths; never leave the shell in another directory.
- Do not run, build or test anything unless I ask for it.
- macOS cannot be tested here. Never ask to test it.
- Files I am supposed to edit: before evaluating, check that the file was saved (timestamp changed). Never delete them before the result is settled.

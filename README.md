# Consolpp

A C++ library for building command-line applications.

## Usage

1. [Installation](docs/INSTALLATION.md): CPM, targets, includes.
2. [Application](docs/APPLICATION.md): `main`, `CommandManager`, built-in commands, global options, errors.
3. [Commands](docs/COMMANDS.md): definitions, options, arguments, reading parameters.
4. [Output](docs/OUTPUT.md): writing, verbosity, flushing.
5. [Markup](docs/MARKUP.md): tags, colors, links, custom tags, escaping.
6. [Input](docs/INPUT.md): reading input, prompts, forms.
7. [Screen](docs/SCREEN.md): sections that update in place, layout.
8. [Completion](docs/COMPLETION.md): shell completion.
9. [Events](docs/EVENTS.md): signals, timers, descriptors.
10. [Text](docs/TEXT.md): UTF-8, graphemes, display width, wrapping.
